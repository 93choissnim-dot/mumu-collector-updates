창키 도우미 v0.7.11

- 짧게 누른 중지 키도 감지하도록 개선했습니다.
- 설정창과 메인 목록의 변경 사항이 서로 덮어쓰지 않도록 수정했습니다.
- 일시중지 중 업데이트 요청 시 수령을 중지하고 업데이트합니다.
- 화면 크기와 배율에 맞춰 창을 조정하고 좁은 화면에서는 목록과 상세 보기를 전환합니다.
- 완료된 업데이트의 불필요한 파일을 정리하고 최근 복구본 두 개를 보관합니다.
- 시설과 수령 간격을 선택한 뮤뮤에 일괄 복사할 수 있습니다.
- 실패 원인과 해당 실패 화면을 확인하고, 실패한 작업만 재시도할 수 있습니다.
- 뮤뮤별 오늘 완료 건수, 마지막 성공 시각과 연속 실패 횟수를 표시합니다. 완료 건수는 이번 버전 이후부터 집계합니다.
- 작업 완료 후 게임 절전 모드로 자동 복귀하며, 선택 스위치는 제거했습니다.
- 시설과 추가 작업에 전체 선택, 전체 해제 버튼을 추가했습니다. 전체 선택에는 수련도 포함됩니다.

창키 도우미 v0.7.10

- 승인한 게임 테마 시안을 실제 프로그램에 적용했습니다.
- 밝은 양피지색 화면, 금속 테두리, 각진 청록색 버튼을 적용했습니다.
- 뮤뮤 목록을 게임 랭킹 메뉴처럼 행과 구분선으로 정리했습니다.
- 선택한 뮤뮤는 금색으로 강조하고, 상태별 색상과 문구를 표시합니다.
- 연결, 실행 대상, 확인 필요 수를 한 줄로 모았습니다.
- 오른쪽 결과 목록에 작업 아이콘을 추가했습니다.
- 세팅 설정, 중지 키 설정, 업데이트 창도 같은 테마를 사용합니다.
- 기존 뮤뮤별 저장 설정, 수령 기능, 일시중지와 자동 업데이트를 유지합니다.
