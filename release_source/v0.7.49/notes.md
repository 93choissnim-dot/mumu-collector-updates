# 창키 도우미 v0.7.49

- 공방약탈은 이전 전투 결과가 불확실해도 재실행할 수 있도록 변경했습니다. 재실행마다 공방 상세 화면과 전투 버튼을 다시 확인한 뒤 한 번만 진입하며, 결과 화면을 확인해야 완료로 기록합니다.
- 보류 횟수와 실제 실패 횟수를 분리합니다. 이전 버전에서 두 상태가 섞여 집계된 숫자는 별도 과거 기록으로 표시합니다.
- 기부와 수련 등 이전 입력 결과 확인이 필요한 작업의 재시도는 보류 해결 창으로 연결합니다. 공방약탈은 이 확인 절차 없이 재시도할 수 있습니다.
- 입력 요청의 최초 시각과 앱 버전을 보존하고, 결과 확인 기록을 따로 남깁니다. 이전 버전에 없던 시각이나 버전은 추정하지 않습니다.
- 일일 작업의 입력 직전 화면과 결과 확인 화면을 계정과 항목별로 제한하여 PC에 저장합니다. 같은 보류를 다시 확인해도 최초 요청 기록이 바뀌지 않습니다.
