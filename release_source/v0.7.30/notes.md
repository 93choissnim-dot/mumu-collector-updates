월드보스의 불필요한 재진입과 업데이트 서버 지연 대응을 개선했습니다.

- 처음 선택창에서 수령 대상 전체를 확정하고 대상만 순서대로 확인
- 마지막 대상 처리 후 선택창을 다시 열지 않고 종료
- 다음 대상이 준비중이 되거나 알림이 사라지면 건너뛰기, 클릭 직전 재확인 유지
- 이전 입력의 결과가 미확인인 보스는 알림이 없어도 확인하고 중복 수령 입력 방지
- HTTP 504 등 일시적인 서버 오류를 최대 3회 재시도, 취소 및 전체 시간 제한 유지
- 끊긴 다운로드는 처음부터 다시 받고 크기 및 SHA-256 검증 유지
- 업데이트 다운로드 진행량과 검증 단계를 화면에 표시

서버 자체의 장애를 제거하는 변경은 아닙니다. 기존 버전에서 504 오류가 지속되면 이번 EXE를 직접 다운로드하여 교체할 수 있습니다.
모의 실행에서 대상 1개일 때 선택창 진입 2→1회, 대상 3개일 때 4→3회를 확인했습니다.
