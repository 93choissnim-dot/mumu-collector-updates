# 창키 도우미 v0.7.74

- 연결 끊김 알림에서 **가운데 ‘확인’ 버튼 하나만 있는 창**을 감지하지 못하던 오류를 수정했습니다. 기존 취소·확인 두 버튼 창과 함께 지원합니다.
- 연결 끊김 문구를 먼저 확인하고, 활성화된 확인 버튼의 위치가 클릭 직전에도 같은지 재검사합니다. 버튼이 비활성화되거나 사라진 경우에는 연결 끊김으로 표시하고 입력을 보류합니다.
- 실제 보고된 알림 창을 개인정보가 없는 UI 검증 자료로 추가했습니다. 절전 화면 위 알림, 확대·축소와 고해상도 입력 좌표, 감시 자동 복구, 클릭 직전 창 변경, 중복 확인 방지를 검사합니다.

기존 무료 소환 결과 펼치기 수정, 레드루비 포함 길드 기부 전 횟수, 길드 던전 도전 소진 후 수령, 진단 보관 5일 설정을 유지합니다.
