# 창키 도우미 v0.7.99

- 획득 알림이 월드보스 이름·빨간 표시를 가려 목록 인식이 중단되는 문제를 수정했습니다.
- 제목·닫기·세 보스의 하단 설명을 함께 검증합니다. 표시가 가려지면 준비 중 보스를 제외한 랭킹창을 한 번씩 확인하며 실제 보상 버튼과 이전 입력 보호를 유지합니다.
- 알림이 사라져도 안전한 하단 클릭 위치를 유지합니다.
- 기록 저장의 일시적 Windows 접근 거부를 제한적으로 재시도합니다. 지속 오류에서는 기존 기록을 보존하고 입력을 중지합니다.

기존 기록 삭제 없이 업데이트 후 수령을 다시 실행하세요.
