# 창키 도우미 v0.7.73

- 캐릭터·스킬·펫 무료 소환에서 **‘터치하여 결과 모두 확인’ 화면에 멈추는 오류**를 수정했습니다. 안내 문구와 소환 종류를 함께 확인해 결과를 펼치고, 결과 확인 후 남은 무료 횟수를 이어서 사용합니다.
- 결과 펼치기 화면에서 중단한 뒤 다시 시작해도 펼치기 → 결과 닫기 → 기본 화면 복귀 순서로 정리합니다. 이미 요청한 소환은 남은 횟수로 확인하며 중복 요청하지 않습니다.
- 클릭 직전 화면 변경으로 **실제 입력이 전송되지 않은 경우**에만 새로 만든 보류 기록을 해제합니다. 전송 오류나 이전 미확인 요청은 그대로 보존합니다. 진단 기록에서도 미전송과 결과 확인을 구분합니다.
- 세 종류의 소환 영상과 보고된 화면을 개인정보를 제외한 UI 검증 자료로 추가했습니다. 무료 2회 전체 흐름, 중간 재시작, 다른 종류 결과 화면에서의 복귀, 화면 변경과 반복 터치 제한을 검사합니다.

무료 소환·상점 무료 수령, 레드루비 포함 길드 기부 전 횟수, 길드 던전 도전 소진 후 수령, 진단 보관 5일 설정을 유지합니다.
