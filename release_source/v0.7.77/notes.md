v0.7.77 진단 기반 무료 작업·기부 수정

- 실제 화면에서 놓친 광고 무료 루비와 길드 상점 수령 후 상품 이름 인식을 보완했습니다. 유료 가격과 무료 버튼의 기존 엄격한 구분은 유지합니다.
- 한 열에 유료·무료 루비 상품이 함께 있을 때 아래 무료 상품도 찾습니다.
- 입력 직전 화면 변경이나 ADB 미전송으로 취소된 기부는 이번 예약과 시도 횟수만 되돌립니다. 전송 여부가 불확실한 기록은 보존합니다.
- 전날 무료 소환 기록이 남아도 오늘 화면에서 무료 2/2와 소환 종류를 확인하면 새 일일 무료 횟수로 진행합니다. 전날 결과를 성공으로 바꾸지 않습니다.
- 길드 무료 코인의 보상 근거를 창을 닫기 전에 저장하며 재실행 후에도 중복 입력 없이 반영합니다.
- 상점 상품 영역이 두 번 연속 바뀌지 않으면 같은 방향의 불필요한 스크롤을 중단합니다.

검증: 계정 정보를 제거한 실제 상품/버튼 화면과 실제 기록 저장·입력 경계 회귀 테스트를 추가했습니다. Windows 전체 테스트, 폴더/단일 EXE 실행 및 업데이트·재시작·복구 검증을 통과한 빌드만 공개합니다.
제한: 사용자 PC에서 실시간 게임 동작을 직접 실행한 검증은 아닙니다. 과거 유료 기부의 전송 여부가 불확실한 기록을 임의 성공 처리하거나 자동 재결제하지 않습니다.
