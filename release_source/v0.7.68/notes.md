# 창키 도우미 v0.7.68

- 월드보스 상세 화면의 보급상자 주변 배경과 알림 표시가 바뀌어도 고정된 상자 무늬로 화면을 확인합니다. 임무와 랭킹을 포함한 세 가지 화면 확인 조건은 유지합니다.
- 여러 작업과 상태 화면이 같은 작업 기록을 다룰 때 임시 파일이 충돌하거나 이전 내용으로 덮어쓰는 문제를 수정했습니다.
- Windows의 일시적인 파일 공유 잠금은 짧게 재시도하며, 저장 실패 시 운영체제 오류를 진단에 남깁니다. 기록이 저장되지 않으면 게임 입력은 계속 보류합니다.
- 기존 미확인 수령 기록과 중복 클릭 방지는 유지합니다. 길드 기부는 레드루비를 포함한 전체 횟수, 길드 던전은 도전 횟수 소진 후 전리품 수령 기준을 유지합니다.

새 화면 인식과 동시 저장에 대한 회귀 검사를 추가했습니다. 배포는 Windows 전체 검사, 실제 EXE 실행, 업데이트와 재시작 및 복구 검증을 통과한 빌드에만 진행합니다.
