창키 도우미 v0.7.93 — 이어하기·기록 격리·복구 감시 보완

- 무료 수령은 미완료 이어하기에서도 현재 화면을 다시 확인합니다. 같은 실행에서 새로 실패한 입력과 유료 작업의 중복 입력 보호는 유지합니다.
- 다른 계정의 기록 항목이 손상돼도 정상 계정은 처리합니다. 손상된 계정은 원본을 보존하고 기록 확인 필요로 안내합니다. 옛 일일 기록 이관·반복 실행·오늘 작업 표시에도 적용합니다.
- 기록 파일 전체가 읽히지 않거나 저장이 실패하면 입력을 중지합니다. 손상된 유료 기록을 초기화하거나 백업으로 자동 덮어쓰지 않습니다.
- 현재 수령 중인 뮤뮤를 제외한 다른 선택 뮤뮤를 작업 사이에 점검합니다. 알 수 없는 화면이 30초 이상 지속되면 확인 필요, 작업 중 점검이 60초 이상 늦어지면 점검 지연으로 표시합니다. 알 수 없는 화면을 이유로 강제 재시작하지 않습니다.
- 손상된 인식 재확인 시각 때문에 계속 보류되는 예외를 개선했습니다. 미확인 입력 자체의 보호는 별도 유지합니다.
- 무료 수령의 입력 번호와 클릭 직전 증거를 추가하고, 실행별 첫 실패 ZIP을 최근 12건·총 24MiB 이내로 보존합니다. 진단 ZIP의 기존 전체 용량 제한은 유지합니다.
