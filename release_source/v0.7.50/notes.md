# 창키 도우미 v0.7.50

- 일일 던전과 길드 던전에서 결과 확인 여부를 사용하도록 수정했습니다. 결과 또는 확인된 클리어 화면 없이 돌아온 경우 입력 결과를 미확인으로 유지합니다.
- 입장 횟수 0과 무료 입장 상태를 연속으로 확인한 뒤 완료로 기록합니다. 남은 횟수 0만으로 이전 미확인 입력을 성공 처리하지 않습니다.
- 소탕 보상창이 자동으로 닫힐 때 결과를 놓치는 문제를 수정했습니다. 현재 요청 이후 확인한 보상과 이전 입력을 구분합니다.
- 기록창에 던전 완료 재확인을 추가했습니다. 완료 상태에서도 화면과 잔여 횟수만 다시 확인하며, 입장권 사용이나 소탕은 실행하지 않습니다.
- 확인 근거가 없는 이전 완료 항목은 명시적 재시도에서 먼저 화면만 재확인합니다. 잔여 횟수가 있거나 확인하지 못하면 완료 표시를 해제하고 재시도가 필요한 상태로 남깁니다.
- 전투 결과와 남은 횟수 없음의 확인 화면을 각각 제한된 개수로 PC에 보존합니다.
