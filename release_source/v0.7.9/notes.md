창키 도우미 v0.7.9

- 실제 뮤뮤 목록을 중심으로 메인 화면을 새로 구성했습니다.
- 뮤뮤별 실행 대상, 현재 상태, 작업 진행, 다음 수령 시간을 목록에서 확인합니다.
- 이름 검색, 실행 대상과 확인 필요 필터를 추가했습니다.
- 오른쪽에는 선택한 뮤뮤의 최근 캡처와 작업별 기록을 표시합니다.
- 메인 화면의 중복 간격 설정을 없애고 뮤뮤별 세팅으로 모았습니다.
- 세팅은 뮤뮤 선택 목록과 작업 영역으로 나누고, 자원 시설과 추가 작업을 구분했습니다.
- 수련 재료 사용과 월드보스의 빨간 표시 조건을 설정에 표시합니다.
- 저장 전 수정 내용을 유지하며, 다른 뮤뮤를 조회해도 기존 설정을 덮어쓰지 않습니다.
- 시작, 일시중지, 재시작, 중지 버튼을 하단에 고정하고, 실행 기록은 펼쳐 볼 수 있습니다.
- 기존 중지 키, 뮤뮤별 설정, 수령 기능과 자동 업데이트를 유지합니다.
