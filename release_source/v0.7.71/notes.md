# 창키 도우미 v0.7.71

- 입력 안전성과 이어하기를 담당하는 기록의 저장·읽기 오류는 일반 연결 오류와 분리합니다. 현재 실행, 다음 계정과 예약 재시도, 게임 자동 복구를 중단하며 기록 확인 후 사용자가 다시 실행하도록 합니다.
- 일일 작업 기록·새 실행 기록·수령 이력을 고유 임시 파일, 디스크 동기화, 원자적 교체로 저장합니다. Windows 공유 잠금 오류는 짧게 재시도하며 실패 시 이전 파일과 메모리 기록을 보존합니다.
- 월드보스 정산 대기만 남은 계정을 확인 필요로 잘못 표시하던 문제를 수정했습니다. 실제 실패나 미확인 항목이 함께 있으면 확인 필요 표시를 유지합니다.

이전 무료 수령 보류의 조건부 복구, 진단 보관 5일, 레드루비를 포함한 길드 기부 전 횟수 사용, 길드 던전 도전 소진 후 전리품 횟수와 무관한 수령 방식을 유지합니다.
