# 창키 도우미 v0.7.75

- 재접속 시간 초과 후 정상 화면 확인 없이 감시 점검 완료로 바뀌던 문제를 수정했습니다. 다른 앱이 앞에 떠 있어도 미확인 상태를 유지합니다.
- 감시 복구는 화면을 한 단계씩 확인하고 제어를 돌려줍니다. 로딩을 90초 또는 다운로드를 5분 동안 기다리는 루프가 예약 작업을 가로막지 않습니다. 실제 ADB 응답 지연에는 기존 제한 시간이 적용됩니다.
- 무료 상점 보상은 현재 계정·날짜·상품·수령 요청과 연결된 확인 기록을 창을 닫기 전에 저장합니다. 직후 종료되어도 같은 요청의 보상 확인 기록으로 완료를 복구하며, 근거 없는 이전 보류 기록은 유지합니다.
- 올바른 상점 탭에서 무료 상품이 이미 보이면 탭 재선택과 위로 세 번 스크롤을 생략합니다.
- 공통 인식, 무료 소환·상점, 상단 메뉴 아이콘, 이벤트 인식에서 고정 기준 이미지 계산을 재사용합니다. 관측 화면·입력 직전 재확인·인식 임계값은 유지합니다.
- 감시 중 뮤뮤 관리자 위치 탐색 정보를 재사용하고, 현재 뮤뮤 식별과 연결 상태는 계속 확인합니다.

무료 작업의 유료 재화 사용 금지, 레드루비 포함 길드 기부 전 횟수, 길드 던전 도전 소진 후 수령, 진단 보관 5일을 유지합니다.
