# 창키 도우미 v0.7.47

- 가을맞이, 랭킹, 발굴, 월드 보스: 이전 수령 결과가 보류돼도 사용자가 재시도하면 현재 활성 버튼을 확인한 뒤 한 번만 다시 수령합니다. 중단이나 화면 변경 시 중복 입력을 막는 기록은 유지합니다.
- 길드와 일일 작업: 기록창 재시도가 실제 일일 실행으로 연결되며 완료한 단계는 유지합니다. 결과 미확인 약탈은 상세 화면을 확인하고 전투 재입장을 보류합니다.
- 기록창의 보류 해결에서 게임 내 결과를 직접 확인한 항목만 완료 반영하거나 미실행으로 재시도할 수 있습니다. 수련 등 자원을 쓰는 작업은 자동으로 다시 입력하지 않습니다.
- 기록창은 실행 종료와 상태 변경을 반영합니다. 중지 직후 이전 완료 이벤트가 새 실행의 중지 버튼을 끄는 문제를 막고 재시도 불가 이유를 표시합니다.
- 업데이트 실패 단계, 대상 경로, WinError와 복구 결과를 보존합니다. Windows 앱 제어 정책에 차단된 같은 버전의 자동 재시도를 억제하고 진단 파일에 업데이트 기록을 포함합니다.
- 첫 실패 증거와 최신 화면을 함께 남깁니다. 가을맞이와 수련의 보류 상태도 현재 화면을 저장합니다.

Windows 정책 차단(WinError 4551)의 서명이나 신뢰 조건은 이 변경만으로 해제되지 않습니다. 해당 PC에서 새 EXE 실행 자체가 차단되면 이 버전의 개선도 적용되지 않으며, 신뢰할 수 있는 코드 서명 또는 관리자의 정책 허용 검토가 필요합니다.
