# 창키 도우미 v0.7.48

- 가을맞이에서 실제 ADB 화면의 숫자 테두리 차이로 `0/10`을 읽지 못하던 문제를 수정했습니다. 숫자 전체와 첫 번째 0을 각각 확인하며, 다른 숫자나 읽을 수 없는 화면을 완료로 처리하지 않습니다.
- 가을맞이 화면에서 보상 0개와 비활성 수령 버튼을 확인하면 이전 수령 보류 기록을 추가 클릭 없이 해제합니다. 보상이 남아 있고 이전 결과가 불명확한 경우에는 기존 재시도 확인 절차를 유지합니다.
- 패스 화면 진입 시 확인된 상단 패스 아이콘을 바로 사용해 불필요한 메뉴 닫기를 줄입니다.
- 밝은 배경에서 메인 화면과 패스 아이콘을 놓치던 인식을 보완합니다. 메뉴 열기 입력 후에도 메인 화면에 머무르면 새 화면 확인을 거쳐 제한적으로 다시 열며, 다른 창이나 알 수 없는 화면에서는 재입력하지 않습니다.
- 실제 실패 화면에서 개인정보와 채팅을 제거한 회귀 검사 이미지를 추가하고 Windows EXE 내부 검사에도 포함합니다.
