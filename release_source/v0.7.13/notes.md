창키 도우미 v0.7.13

- 시작할 때 다른 게임 창이 열려 있으면 ESC 동작으로 한 단계씩 닫고 초기화면을 확인합니다.
- 게임 종료 확인창이 뜨면 취소를 누른 뒤 화면을 다시 확인합니다.
- 절전 모드 해제 후 오른쪽 메뉴가 바로 보이면 ESC 없이 수령을 시작합니다.
- 이미 초기화면이나 오른쪽 메뉴에 있으면 불필요한 뒤로가기를 보내지 않습니다.
- 복귀 횟수와 대기 시간을 제한하고, 중지 및 일시중지 후 화면 재확인을 유지합니다.
- 기존 공통 수령 간격과 수령 후 절전 복귀 동작을 유지합니다.

검증: 제공된 초기화면/종료창 캡처, 인식 변형, 모의 화면 전환, Windows EXE 및 업데이트 검사. 실제 MuMu 게임 조작은 사용자 환경에서 확인이 필요합니다.
