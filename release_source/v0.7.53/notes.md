# 창키 도우미 v0.7.53

수련 완료 확인과 유료 패스 화면 인식을 보완했습니다.

- 수련 버튼이 계속 활성 상태여도 클릭 전후 수련 레벨 상승을 연속 화면에서 확인해 완료 처리합니다.
- 입력 전에 기준 레벨을 기록해 재시작 후에도 미확인 수련의 결과를 확인합니다. 근거 없는 완료 처리와 중복 입력은 하지 않습니다.
- 수련 입력 직전과 결과 확인 화면을 진단 파일에 포함합니다.
- 일부 던전/장비 멤버십의 가격 표시를 놓치던 화면 판별을 보완했습니다. 유료 항목은 결제하지 않고 완료로 넘깁니다.

이전 버전에서 이미 보류된 수련은 클릭 전 레벨 기록이 없어 자동으로 완료 여부를 확정할 수 없습니다. 실행을 중지한 뒤 기록창의 수련 재시도에서 실제 결과를 확인해 보류를 해결하세요.
