# 창키 도우미 v0.7.46

- 벌목소, 농장, 광산에서 이전 수령 결과 미확인 기록 때문에 수동 재시도가 즉시 보류되던 문제를 수정했습니다.
- 사용자가 재시도를 선택하면 현재 시설과 활성 수령 버튼을 확인한 뒤 무료 자원 수령을 한 번 다시 시도합니다.
- 이미 비어 있으면 클릭 없이 상태를 확인하고, 수령 후 완료를 확인하지 못하면 보류 기록을 유지합니다.
- 재연결이나 자동 수령으로 같은 입력이 반복되지 않도록 수동 재시도 권한은 실행당 한 번만 사용합니다.
- 실행 기록에는 이전 입력을 합산하지 않고 이번 실행의 클릭 횟수를 표시합니다.
