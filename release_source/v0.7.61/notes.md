창키 도우미 v0.7.61

- 하단에 게임 자동 복구 스위치와 상태를 추가했습니다. 기본 켜짐이며 실행 대상으로 체크한 뮤뮤를 감시합니다. 작업 중지 및 예약 대기 중에도 약 15초 간격으로 점검합니다. 수령 예약 시간과 완료 기록은 바꾸지 않습니다.
- 작업, 화면 조회와 별도 감시가 동시에 게임을 조작하지 않습니다. 일시정지 중에는 입력하지 않으며, 스위치를 끄면 진행 중인 복구도 취소됩니다. F8은 작업과 자동 복구 감시를 함께 중지합니다.
- Android 홈 화면이고 지원하는 게임 프로세스가 없는 경우에만 재실행합니다. 실행 중이던 원스토어판 또는 일반판을 기억하며, 판본을 확정할 수 없으면 임의로 선택하지 않습니다.
- 같은 뮤뮤 재실행은 10분 동안 최대 두 번이며 실패 시 점검 간격을 늘립니다. 다른 앱을 사용 중이거나 게임 프로세스가 살아 있으면 재실행하지 않습니다.
- 정확한 '다운로드를 시작합니다.' 안내와 활성 확인 버튼을 다시 확인한 뒤 한 번만 누릅니다. 다운로드는 최대 5분 기다리며, 다른 구매, 로그인, 인증 안내를 임의로 누르지 않습니다.
- 재접속 뒤 인식된 오프라인 보상 확인을 처리하고 정상 화면을 확인한 뒤 진행 중인 수령을 이어갑니다. 복구가 중단돼도 시작 화면 처리 기록을 유지해 불확실한 확인 입력을 반복하지 않습니다.
- 미완료 이어하기와 하단 작업 선택 영역을 매번 숨겼다가 다시 배치하던 동작을 제거해 깜빡임을 줄였습니다.

게임을 직접 종료하려면 자동 복구 스위치를 먼저 꺼 주세요. MuMu 또는 도우미 자체가 종료된 경우는 복구 대상이 아닙니다. 검증은 자동 회귀, Windows 화면과 EXE, 업데이트 절차이며 실제 사용자 계정에서 새 복구 흐름의 전체 실사용 검증은 별도입니다.
