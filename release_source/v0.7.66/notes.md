창키 도우미 v0.7.66

- 길드 던전은 도전 횟수를 모두 사용하면 전리품 숫자나 알림 유무와 관계없이 수령 버튼을 실행합니다.
- 도전 횟수 0과 수령 버튼을 누르기 직전 화면에서 다시 확인합니다. 보상창 또는 수령 완료 상태가 확인되면 다음 작업으로 넘어갑니다.
- 전리품 숫자 인식 때문에 보류된 이전 기록은 미확인 입력이 없는 경우 다시 진행합니다. 결과를 확인하지 못한 수령은 자동으로 반복하지 않습니다.
- v0.7.65의 레드루비 기부 전체 횟수 지원과 업데이트 시작 검사 개선은 유지합니다.

재현 검사와 Windows 실행 및 업데이트 검증을 거쳐 배포합니다. 실제 사용자 MuMu 계정의 전체 루틴을 직접 실행한 검증은 아닙니다.
