# 창키 도우미 v0.7.78

- 월드보스의 새 일반·통합 서버 선택창을 인식하고 **일반**으로 진입합니다. 두 선택지와 닫기 버튼을 확인한 후 입력하며, 화면이 바뀌거나 확인되지 않으면 누르지 않습니다.
- 무료 루비와 광고 루비의 `일일 구매 0/1` 및 재구매 대기 화면을 소진 상태로 인식하도록 보완했습니다.
- 이전 날짜의 무료 소환 미확인 기록이 남아 있고 오늘 횟수가 `0/2`인 경우, 이전 기록은 미확인 상태로 보존하고 오늘은 소진 완료로 처리합니다. 추가 소환 입력은 보내지 않습니다.
- 제공된 화면을 재현한 인식 검사와 입력·기록 보존 검사를 추가했습니다. 배포 전 Windows UI, 실행 파일, 업데이트·재시작·복구 검증을 수행합니다.

사용자 PC에서 게임을 직접 조작한 검증은 아닙니다. 제공된 캡처·진단과 자동 검증을 근거로 수정했습니다.
