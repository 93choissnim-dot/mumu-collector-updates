창키 도우미 v0.7.62

- 실행 중 또는 예약 대기 중에도 “연결이 끊겼습니다. 네트워크 상태를 확인하고 다시 시도해 주세요.” 오류창을 구분합니다.
- 정확한 오류 문구와 취소 및 확인 버튼 배치를 확인하고, 최신 화면에서 오른쪽 확인이 활성 상태일 때만 한 번 누릅니다. 다른 팝업이나 비활성 버튼은 누르지 않습니다.
- 해당 창을 게임 종료 확인창으로 오인하지 않도록 우선 인식하며, 수령 작업은 입력을 멈추고 기존 기록을 유지한 채 복구로 넘깁니다.
- 확인 후 정상 게임 화면까지 기다립니다. 다운로드 안내나 오프라인 보상이 이어지면 기존 확인 절차로 처리합니다. 진행 중이던 수령은 완료 및 결과 미확인 기록을 보존해 안전하게 이어갑니다.
- 같은 오류창이 계속 남거나 결과를 확인할 수 없으면 확인을 연타하지 않습니다. 정상 화면 복귀가 검증된 뒤 새로 발생한 오류만 다시 처리합니다.
- 게임 자동 복구 스위치, 일시정지, F8 중지 및 대상 뮤뮤 확인 규칙을 그대로 적용합니다. 유료 구매나 계정 인증을 자동 처리하지 않습니다.

검증은 제공된 오류창 인식, 재현 테스트, Windows 화면과 EXE 및 업데이트 절차입니다. 새 네트워크 오류 복구 흐름의 사용자 MuMu 실사용은 아직 직접 검증하지 않았습니다. 전체 사용자 화면은 공개하지 않고 비식별 오류 문구와 버튼 조각만 인식 자료에 포함했습니다.
