창키 도우미 v0.7.25

- 세팅 설정 > 수령할 작업에 가을맞이 수령 추가 (기존 설정은 선택 해제 상태)
- 이벤트 목록에서 가을맞이 항목을 찾아 누적 재료만 수령
- 기존 공통 간격 1시간 / 2시간 / 3시간 또는 직접 입력 간격으로 반복 확인
- 같은 날에도 다시 쌓인 재료 수령 가능
- 보상 0/10이면 수령 대기, 이벤트 항목이 없으면 이벤트 없음 표시
- 수령 후 상태 확인과 메뉴 및 절전 복귀 지원
- 강화나 다른 이벤트 기능은 실행하지 않음
