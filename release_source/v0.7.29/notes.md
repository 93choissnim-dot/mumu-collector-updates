- 연속 화면과 버튼 확인 결과 공유, 입력/일시정지/연결 복구/시간 경과 시 폐기
- 클릭 직전 별도 새 캡처와 버튼 상태 재확인 유지
- 던전 목록 외 화면의 카드 검색 생략, 고정 기준 이미지 계산값 재사용
- 길드 상점과 던전에서 길드 내부로 돌아가 기본 화면 왕복 감소
- 확인된 화면 전환은 대기 조기 종료, 전투 결과와 유료 기부 검증은 별도 처리
- 뮤뮤 관리 프로그램 경로와 캡처 방식 재사용, 기기 신원과 주소는 매번 새로 확인
- 같은 대기 알림 중복 제거, 대기 중 목록 갱신 감소

제공된 화면 재현 기준 캡처 횟수: 패스 37→23, 던전 233→175, 길드 99→66.
