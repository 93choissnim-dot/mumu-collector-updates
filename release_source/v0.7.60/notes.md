창키 도우미 v0.7.60

- 하단에서 일반 작업, 일일 작업, 전체 범위를 선택하고 한 번 실행합니다. 자동 실행은 일반 작업만 반복합니다. 일일 작업은 설정에서 각각 선택할 수 있습니다.
- 미완료 이어하기를 하단에 배치하고, 실행 가능한 작업과 결과 미확인 보류 항목을 계정별로 구분합니다. 실행 직전에 다시 확인하며 보류된 소탕이나 전투를 자동 반복하지 않습니다.
- 다른 작업을 새로 실행해도 기존 미완료 기록을 유지합니다. 이어하기는 같은 계정 구분과 한국 날짜의 기록만 사용합니다.
- 이번 실행 대기 및 결과와 이전 기록을 구분하고, 현재 보는 계정과 실제 실행 중인 계정을 표시합니다. 중지 후에도 실행 요약을 유지합니다.
- 상단 높이를 줄이고 보조 글자를 키웠으며, 실행 중에는 일시정지와 중지를 우선 배치합니다.
- 게임이 종료되어 Android 홈으로 돌아왔고 게임 프로세스가 없는 것을 확인한 경우에만 창세기전 키우기를 다시 실행합니다. 대상 뮤뮤를 재확인하며 최대 두 번, 재접속마다 최대 90초 동안 정상 화면을 기다립니다.
- 다른 앱으로 전환했거나 게임이 아직 실행 중이면 재실행하지 않습니다. 로그인 및 인증이나 알 수 없는 화면에는 입력하지 않고 대기 제한 후 중지합니다. 사용자가 중지하거나 조회만 하는 경우에는 재접속하지 않습니다. MuMu 자체 재실행은 포함하지 않습니다.
- 재접속 후에도 이전 완료와 미확인 입력 기록을 유지하고 불확실한 자원 소모 행동을 반복하지 않습니다.
- 수련의 활성 버튼 반복, 무료 열쇠 이후 소탕, 보물 전투 대기, 길드 보류 구분과 유료 구매 금지 원칙을 유지합니다.

검증 범위: 자동 회귀 검사, Windows UI 배율 및 단일 EXE 실행, 업데이트 교체와 재시작 및 복구. 실제 사용자 MuMu 계정 전체 루틴 및 실제 게임 종료 후 로그인 과정은 실사용 미검증입니다. 게임 앱이 인증이나 인식하지 못하는 시작 화면에 머물면 직접 접속한 뒤 이어하기가 필요합니다.
