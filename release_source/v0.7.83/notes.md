# 창키 도우미 v0.7.83

- 상점·소환·패스·던전·길드 진입에서 클릭 직전 화면이 전환된 경우, 현재 화면을 다시 확인해 이어갑니다. 이미 목표 화면이면 다시 나갔다 들어오지 않습니다.
- 무료 상점 상품과 확인창이 잠깐 바뀌어 입력이 전송되지 않은 경우 최대 3회 다시 확인합니다. 이미 전송한 구매나 결과 미확인 구매는 자동 반복하지 않습니다.
- 던전 카드 진입과 실패 후 목록 복귀에도 같은 화면 변경 복구를 적용했습니다.

- 오늘 완료 표시는 이전 날짜의 미확인 상점·패스·기부 입력을 성공으로 바꾸지 않습니다. 원래 결과는 미확인으로 보존합니다.
- 원스토어판도 확인된 일일 작업 화면에서 연결·복귀할 수 있도록 판본별 조건을 맞췄습니다.

기존 전체 회귀 검증에 무료 상품 3종의 지연·중지·응답 유실 시뮬레이션, 전투 로딩 경계 조건, 모든 일일 진입 경로 검증을 추가했습니다. 실제 사용자 기기에서의 실시간 게임 검증과는 구분됩니다.
