과거 기록 때문에 현재 작업까지 계속 보류되는 원인을 여러 수령 경로에서 점검하고 공통 처리를 보완했습니다.

- 농장·벌목·광산·가을 이벤트·랭킹·발굴·월드보스의 무료 수령 예약과 보상 확인을 공통 처리합니다.
- 확실히 전송되지 않은 입력은 이번 예약만 정리합니다. 입력 전송 여부가 불확실한 기록은 보존합니다.
- 현재 수령에 해당하는 보상창을 확인하면 닫기 전에 기록합니다. 상점 보상 근거도 첫 닫기 확인 전 저장해 캡처 중단 후 재실행에 반영합니다.
- 단순 화면 인식 반복 실패는 5분 대기 후 현재 화면을 다시 확인합니다. 유료 입력과 미확인 결과는 시간이 지났다는 이유로 해제하지 않습니다.
- 대기 시간이 지난 인식 실패가 과거 보류 표시 때문에 이어하기에서 다시 제외되는 문제를 수정했습니다.
