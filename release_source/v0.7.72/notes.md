# 창키 도우미 v0.7.72

- 일일작업에 **무료 소환**을 추가했습니다. 캐릭터·스킬·펫의 무료 횟수를 각각 모두 사용하며, 소환권·다이아·루비를 사용하는 소환 버튼은 실행하지 않습니다.
- 일일작업에 **상점 무료 수령**을 추가했습니다. 무료 루비 100개, 광고 무료 루비 100개, 광고 무료 장비 제작 큐브 4,500개를 각각 확인해 수령합니다.
- 화면·무료 표시·남은 횟수를 다시 확인한 뒤 입력합니다. 소환은 횟수 감소, 상점은 실제 보상 표시를 확인해야 완료로 기록합니다. 보상 지연은 기다리고 결과가 불분명하면 중복 입력을 보류합니다.
- 계정별 선택, 오늘 작업, 이어하기와 결과 기록에 새 항목을 연결했습니다. 기존 일일작업을 사용 중인 계정에는 새 항목을 기본 선택하며, 명시적으로 해제한 선택은 유지합니다.
- 광고 화면이 남아 있을 때 임의 닫기나 유료 구매를 시도하지 않습니다. 확인 시간 초과 시 현재 상태를 보존합니다.

길드 기부 전 횟수 사용(레드루비 포함), 길드 던전 도전 소진 후 전리품 횟수와 무관한 수령, 진단 보관 5일과 기존 안정성 개선을 유지합니다.
