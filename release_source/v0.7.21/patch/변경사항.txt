창키 도우미 v0.7.21

- 장비 보급소 카드가 보여도 찾지 못하던 인식 오류 수정
- 던전 카드 선택 효과로 이름 크기가 달라지는 경우 인식 범위 보완
- 길드 던전의 움직이는 배경 때문에 도전 횟수 0/3을 인식하지 못하던 오류 수정
- 숫자 배경을 제외하고 앞자리와 전체 숫자 형태를 함께 비교
- 0/3과 전리품 0개가 확인되면 전투나 수령을 누르지 않고 다음 단계로 진행
- 이미 수령 및 입장 횟수 없음 표시, KST 자정 초기화 유지

검증: 제공 진단의 장비 보급소 화면과 길드 던전 0/3 화면에서 오류 재현 후 수정 확인. 실제 진단 화면을 목록 및 길드 던전 진입 지점에 사용하고 나머지 전환은 제공 영상 프레임으로 재현했습니다.
회귀 검증은 기존 공개 템플릿의 크기와 배경을 변형하여 수행하며 진단 이미지 자체는 배포 파일에 포함하지 않습니다. 실제 사용자 MuMu에서의 실행은 아직 확인하지 않았습니다.

창키 도우미 v0.7.20

- 패스 진입 위치를 상단 첫 번째 아이콘으로 수정
- 상단 순서: 패스 → 이벤트 → 월드보스 → 상점 → 가방 → 메시지 → 메뉴
- v0.7.18~0.7.19에서 패스 진입에 가방 위치를 사용한 오류 수정
- 테스트와 영상 프레임 재현 코드에도 들어 있던 잘못된 패스 위치 수정
- 패스 이외 6개 아이콘을 누르는 경우 완료로 기록되지 않는지 검증
- 월드보스는 확인된 세 번째 아이콘 위치 유지
- 이미 완료, 이미 수령, 입장 횟수 없음 표시 및 KST 자정 초기화 유지

검증 근거: 사용자가 직접 확인한 아이콘 순서와 전체 진단 화면. 이전 버전의 패스 위치 검증은 잘못된 가정을 공유했으므로 유효한 위치 검증이 아니었습니다.
수정한 위치를 기준으로 화면 전환 모의 테스트와 영상 추출 프레임 재현을 수행했습니다. 실제 사용자 MuMu에서의 실행은 아직 확인하지 않았습니다.

창키 도우미 v0.7.19

- 패스 수령: 당일 수령이 끝났으면 실패 대신 ‘이미 완료’ 표시
- 1일 던전: 입장 횟수와 무료 입장권을 모두 사용했으면 ‘입장 횟수 없음’ 표시
- 길드: 당일 수령이 끝났으면 ‘이미 수령’ 표시
- 같은 날 재실행하거나 프로그램을 재시작해도 완료 상태 유지
- 위 상태는 실패 건수와 자동 재시도에서 제외하고 수령 횟수를 늘리지 않음
- 기록이 없어도 화면에서 수령 완료 또는 횟수 소진이 확인되면 정상 완료로 처리
- 무료 입장권이 남아 있으면 먼저 사용하며 KST 00:00 초기화 유지

검증: 완료 기록 재실행, 완료된 패스 3종, 횟수가 없는 던전 7종, 무료 입장권, 길드 수령 완료, 상태 표시 및 재시도 제외 회귀 검증. 제공 영상의 추출 프레임으로 기존 수령 경로 재현.
화면을 확인하지 못했거나 통신 문제가 발생한 경우는 실제 오류로 유지합니다. 실제 사용자 MuMu에서의 실행은 아직 확인하지 않았습니다.
