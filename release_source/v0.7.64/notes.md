창키 도우미 v0.7.64

- 소탕 보상 뒤 소탕창이 닫히고 던전 방으로 돌아오면, 보상으로 기존 요청을 확인한 뒤 남은 무료 열쇠와 입장 횟수를 이어서 처리합니다.
- 소탕 보상을 확인하지 못한 경우에는 요청 기록을 유지하고 같은 소탕을 다시 누르지 않습니다. 다른 던전으로 이동한 경우에도 자동 재진입하지 않습니다.
- 길드 던전 전리품의 알림 표시가 깜빡이거나 수량이 잠시 인식되지 않으면 현재 수량과 수령 버튼을 다시 확인합니다. 클릭 직전에도 전리품 근거와 남은 입장 횟수 0회를 확인합니다.
- 전리품 요청 기록을 저장해 일시정지나 연결 복구 후에도 결과 미확인 수령을 반복하지 않습니다.
- 위 두 전리품 판정 오류로 보류된 기록은 미확인 입력이 없는 경우에만 다시 확인합니다.
- 전리품 수령은 한 번만 요청하고, 수량 0을 다시 확인한 뒤 완료로 기록합니다. 인식 기준 점수는 낮추지 않았습니다.

제공된 진단에서 확인한 두 화면 전환 오류를 재현 검사로 검증한 수정입니다. Windows 실행 파일, 자동 업데이트, 재시작과 롤백을 배포 절차에서 검사합니다. 사용자의 MuMu 계정에서 전체 루틴을 직접 실행한 검증은 아닙니다.
