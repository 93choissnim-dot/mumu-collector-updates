창키 도우미 v0.7.59

- 기본 창을 680 x 800 크기로 조정하고 사용자가 조절한 크기를 다음 실행에 복원합니다. 화면 배율과 모니터 작업 영역에 맞춰 크기를 제한합니다.
- 좁은 창에서는 상단 동작 버튼을 별도 줄에 배치하여 계정명 잘림을 방지하고, 배경 장식과 여백을 줄입니다.
- 실패와 결과 미확인 작업을 먼저 표시하고, 실행 중에는 행 위치를 유지하면서 현재 작업을 따로 안내합니다.
- 부분 완료와 유료 제외, 오늘 누적 수행 확인과 이번 실행 건수를 구분합니다. 완료는 클릭 수나 획득 재화량이 아닙니다.
- 작업별 실패 이유와 단계별 확인 상태를 기록하고 실행 종료 요약을 표시합니다. 진단 자료는 사용자 PC에만 저장합니다.
- 더보기의 미완료 작업 이어하기로 선택한 계정의 당일 미완료 작업을 재개합니다. 완료한 작업과 이전 날짜/다른 계정의 기록은 이어하기 대상에서 제외합니다.
- 마지막 누락 재점검은 입력 요청이 없었던 인식 실패만 한 번 재탐색합니다. 같은 실행에서 결과 미확인 입력은 재실행하지 않습니다.
- 시작 전 뮤뮤 식별, 게임 앱, 캡처 크기 점검 상태를 표시하고 기존 중지, 안전 복귀, 연결 복구 규칙을 유지합니다.
- 유료 길드 기부 경로를 제거하고 패스와 길드 유료 항목을 명시적으로 제외합니다. 과거 미확인 기부 기록은 성공으로 바꾸지 않습니다.
- v0.7.58의 무료 열쇠 이후 소탕 전환, 실제 버튼 판별, 보물 전투 판별과 길드 보류 복구를 유지합니다.

검증 범위: 자동 회귀 검사, Windows UI와 단일 EXE 실행, 업데이트 교체와 재시작 및 복구 절차. 실제 사용자 MuMu 계정의 전체 루틴 실사용 검증은 수행하지 않았습니다.
