# 창키 도우미 v0.7.52

스톤 채굴장과 보물 창고의 입장 버튼 인식을 보완하고, 전투 시작 확인과 종료 대기를 분리했습니다.

- 실제 던전 화면의 입장 글자 모양을 추가해 화면 크기 변화에서도 확인합니다.
- 버튼의 활성 색상과 클릭 직전 화면을 확인하며 비활성 버튼은 누르지 않습니다.
- 전투 시작은 약 20초 안에 확인합니다. 확인하지 못하면 결과 확인 필요 상태로 남기며 임의로 다시 입장하거나 완료 처리하지 않습니다.
- 전투가 확인되면 그때부터 기존 240초 종료 대기 시간을 적용합니다.
- 공방 약탈 재시도와 던전 완료 재확인 기능은 유지합니다.

업데이트 후 기록창에서 해당 일일 던전을 재시도하세요. 이전 입장 결과가 미확인인 항목은 게임에서 결과를 확인한 뒤 처리해야 합니다.
