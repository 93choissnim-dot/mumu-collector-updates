# 창키 도우미 v0.7.51

길드 공방 가운데 진입 후 전투 버튼을 누르지 못하는 인식 문제를 수정했습니다.

- 공방 이름과 배경색이 바뀌어도 제목의 공통 글자 윤곽과 순위표를 함께 확인합니다.
- 고정 순위표를 기준으로 화면 색 차이를 보정해 전투 버튼을 확인합니다.
- 전투 버튼이 없거나 회색으로 비활성화된 경우 입력하지 않습니다.
- 실제 오류 화면에서 잘라낸 일반 UI 요소로 화면 인식과 입력 직전 검사를 추가했습니다.
- 기존 공방 재시도 정책과 던전 결과 확인, 완료 재확인 기능을 유지합니다.

업데이트 후 기록창의 길드 콘텐츠에서 이 작업만 재시도를 실행하면 됩니다.
