창키 도우미 v0.7.63

- 네트워크 오류창의 배율 보정 후보를 끝까지 확인해 활성 확인 버튼을 놓치는 경우를 수정했습니다.
- 실제 터치 이전에 화면 안전 검사로 중단된 경우를 전송 결과 미확인과 구분해 복구가 영구 보류되지 않도록 수정했습니다. 전송 여부가 불확실한 확인 입력은 반복하지 않습니다.
- 자동 복구에 최근 점검 시각을 표시하고, 다른 뮤뮤의 정상 점검이 기존 복구 오류를 가리지 않도록 했습니다.
- 소환 및 장비 던전에서 무료 열쇠가 그대로 남으면 무료 표시와 0회 상태를 새로 확인해 제한적으로 재수령합니다. 소탕은 별도로 확인하고 결과 미확인 소탕을 반복하지 않습니다.
- 무료 입장권 수령 직후 화면이 안정될 시간을 두고 최신 입장 상태를 다시 검사합니다. 보물 창고에서 요청한 입장의 결과가 불확실하면 중복 입장을 계속 금지합니다.
- 길드 무료 기부 보상이 늦게 표시되면 보상 처리 후 닫기를 재확인합니다. 유료 기부를 누르지 않습니다.
- 입력 요청 기록과 ADB 전송 완료 기록을 구분해 다음 진단에서 전달 여부를 확인할 수 있게 했습니다.

제공된 진단과 재현 검사에 근거한 수정입니다. 보물 창고 입장이 실제로 처리되지 않은 게임 내부 원인은 확정되지 않았으며, 화면 전환 대기와 입력 기록을 보강했습니다. 사용자의 MuMu 계정에서 새 버전 전체 루틴을 직접 실행한 검증은 아닙니다.
