# 창키 도우미 v0.7.54

- 장비와 소환 소탕 무료 열쇠, 룬 던전 입장 버튼의 실제 화면 인식을 보완했습니다.
- 횟수와 무료 열쇠가 모두 0이면 두 번 확인한 뒤 소탕 창을 열지 않고 완료합니다.
- 길드 던전의 별도 전투 화면과 24개 등 다양한 전리품 수량을 처리합니다. 수령 후 0개가 확인되어야 완료합니다.
- 길드 상점의 변경된 상품 구성을 인식합니다.
- 검은 로딩 화면에서는 제한 시간 동안 정상 화면을 기다린 뒤 복귀합니다.
- 비활성 길드 전투 버튼의 회색 색상은 입력 대상으로 인정하지 않습니다.
- 이번에 수정한 인식 문제로 보류된 작업만 다시 확인합니다. 결과가 불확실한 과거 소모 입력은 자동 재실행하거나 완료 처리하지 않습니다.

개인 정보가 없는 작은 UI 조각으로 회귀 검사를 추가했습니다. 유료 패스 구매는 계속 건너뜁니다.
- 시설 복귀 직전에 시설 표시가 사라지면 뒤로가기를 보내지 않고 화면을 다시 확인합니다.
