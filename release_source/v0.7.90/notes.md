# 창키 도우미 v0.7.90

재화 사용 범위, 중지 동작, 연결 진단, 계정 기록 구분과 업데이트 방식을 직접 확인하고 선택할 수 있도록 개선했습니다.

- **재화 사용 설정:** 길드 레드루비 하루 한도는 기본 0으로, 무료 기부만 진행합니다. 기존 설정에 한도가 없어도 0을 적용합니다. 유료 기부는 50 단위, 최대 750까지 선택할 수 있으며 뮤뮤·계정 구분별 한국시간 하루 기준입니다. 결과가 미확인인 기부도 한도에 예약합니다. 수련을 새로 선택할 때 재료 사용 동의를 받고 기존 선택은 유지합니다.
- **완전 중지:** 현재 작업과 반복 대기를 중지하고 게임 자동 복구를 함께 끕니다. 복구 감시는 사용자가 스위치를 직접 다시 켜야 시작됩니다. 일반 중지/F8은 현재 작업 중지용으로 유지됩니다.
- **뮤뮤 연결 설정 · 진단:** 더보기에서 ADB 파일과 로컬 주소·포트를 설정하고 탐색, 기기 연결, 실행 앱, 화면 캡처·인식 결과를 확인합니다. 진단은 읽기 전용이며 게임 터치나 앱 실행·복구를 수행하지 않습니다.
- **저장된 계정 선택:** 실제 게임 계정에 맞는 기록 구분을 목록에서 다시 선택하거나 새 이름으로 저장합니다. 게임 로그인을 바꾸지 않으며 계정별 작업 설정을 불러오는 기능도 아닙니다. 작업·간격·기부 한도 설정은 뮤뮤별로 유지됩니다.
- **업데이트 방식:** 새 설치와 방식이 저장되지 않은 기존 설치 모두 알림만 받기가 기본입니다. 알림 모드에서는 새 버전 확인이 설치·재시작을 하지 않으며, 변경 내용을 보고 업데이트 적용을 직접 누를 수 있습니다. 자동 적용을 선택하면 작업이 끝난 뒤 적용합니다. 알림 모드로 바꾸면 대기 중인 자동 적용을 취소하며, 직접 요청한 적용과 이미 실행된 적용 도우미는 취소하지 않습니다. 저장 실패 시 이전 방식으로 되돌립니다.

## 설치

처음 설치하는 사용자는 무료배포 ZIP을 모두 풀고 `ChankiHelper.exe`를 실행하세요. Python 설치는 필요 없습니다. MuMu와 창세기전 키우기는 별도로 준비해야 합니다. `update.zip`은 기존 설치의 업데이트용입니다.

기존 사용자는 업데이트 창에서 새 버전을 확인하고 적용할 수 있습니다. 이번 버전 적용 이후 업데이트 방식이 저장되어 있지 않으면 알림 모드로 시작합니다. 과거 기부 기록과 기존 수련 선택은 보존하므로 작업 설정을 확인하세요.

상세 설치·설정·문제 해결은 동봉한 `01_설치_세팅_사용법.txt`를 참고하세요. 소스를 직접 실행하는 개발자에게만 Python과 해당 소스의 의존성 설치가 필요합니다.

게임 화면이 변경되거나 뮤뮤 환경이 다르면 추가 확인이 필요할 수 있습니다. 문제 발생 시 더보기의 진단 파일 저장으로 최신 진단을 남겨 주세요.
