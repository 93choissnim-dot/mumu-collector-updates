창키 도우미 v0.7.90 / 설치·세팅·사용법
작성일: 2026-10-23
대상: Windows 64비트 EXE 배포본 사용자 / 개발자용 소스 실행은 13번 참고

1. 어떤 프로그램인가요?

뮤뮤에서 실행 중인 창세기전 키우기의 화면을 확인하고, 선택한 수령·일일 작업을 진행하는 도우미입니다.
PC 마우스 대신 뮤뮤 내부 연결(ADB)을 이용하므로 다른 PC 창에서 문서나 인터넷 작업을 할 수 있습니다.
뮤뮤 안의 게임은 실행 상태로 유지해야 합니다.

이 배포본은 ChankiHelper.exe 단독 실행 방식입니다.
Python, 별도의 파이썬 패키지, BAT 실행 파일을 설치할 필요가 없습니다.
인터넷 연결은 게임 접속과 도우미 업데이트에 필요합니다.

프로그램은 무료로 배포합니다. 게임 재화 사용 여부는 선택한 작업에 따라 달라집니다.
길드 유료 기부 한도의 기본값은 0이며, 수련을 새로 선택할 때는 재료 사용 동의가 필요합니다.
자세한 범위는 아래 5번 설명을 확인하세요.

2. 설치와 뮤뮤 설정

① ZIP 압축을 모두 풀어 계속 사용할 폴더에 보관합니다.
   예: 문서 폴더 안의 ChankiHelper 폴더.
   ZIP 내부에서 실행하지 말고 압축을 푼 ChankiHelper.exe를 실행합니다.
   개인용 폴더에 두면 업데이트 때 파일 교체가 편합니다.

② 뮤뮤를 실행하고 창세기전 키우기에 로그인합니다.
   처음에는 전투 메인 화면으로 돌아온 뒤 팝업을 닫아 두세요.
   게임 내 절전 화면에서도 시작할 수 있습니다.

③ 뮤뮤의 내부 해상도를 가로 16:9로 맞춥니다.
   예: 1280×720 또는 1920×1080.
   PC 모니터 해상도나 바깥 창 크기보다 뮤뮤 내부 게임 화면의 비율이 중요합니다.
   특정 DPI나 FPS 값을 필수값으로 지정하지 않습니다.
   해상도를 바꾼 뒤 재시작이 필요하다는 뮤뮤 안내가 나오면 재시작하세요.

④ 뮤뮤에서 ADB 연결을 제한하는 설정을 사용 중이라면 로컬 연결을 허용합니다.
   메뉴 위치와 이름은 뮤뮤 버전에 따라 다를 수 있습니다.
   처음부터 ADB 포트를 임의로 입력할 필요는 없습니다. 도우미가 실행 중인 뮤뮤를 탐색합니다.
   5555, 7555 같은 숫자를 모든 환경의 정답으로 사용하지 마세요.

⑤ ChankiHelper.exe를 실행합니다.
   첫 실행은 잠시 기다려 주세요. 여러 번 눌러 중복 실행할 필요는 없습니다.
   파일을 별도 설치하지 않고 사용하는 방식이며, 뮤뮤와 게임은 포함되어 있지 않습니다.

3. 뮤뮤 연결과 계정 확인

① 상단 [뮤뮤 연결]을 누르고 연결 확인이 끝날 때까지 기다립니다.
② 뮤뮤가 여러 개라면 목록에서 원하는 뮤뮤 이름을 선택합니다.
③ [화면 확인]을 누르고 [최근 화면]에서 원하는 게임·계정인지 확인합니다.
   미리보기는 마지막으로 캡처한 정지 화면이며 실시간 영상이 아닙니다.
④ 실행할 뮤뮤만 대상으로 체크합니다.
   목록에서 이름을 눌러 보고 있는 것과 실행 대상으로 체크하는 것은 다릅니다.
   실행 대상으로 체크된 뮤뮤들은 순서대로 처리합니다.

자동 복구가 켜져 있으면 선택한 뮤뮤를 감시합니다.
처음 설정하는 동안 게임을 직접 조작하려면 [완전 중지]를 누르세요.
설정을 마친 뒤 복구 감시가 필요하면 [게임 자동 복구]를 직접 다시 켜야 합니다.

4. 처음 사용할 때의 설정 순서

상단 [작업 설정]을 엽니다.

① 왼쪽에서 설정할 뮤뮤를 선택합니다.
② [이 뮤뮤를 실행 대상에 포함]을 켭니다.
③ [수령 간격]을 정합니다. 처음에는 기본값인 60분으로 시험하세요.
   1~1440분 범위이며 1시간·2시간·3시간 선택도 가능합니다.
   이 값은 반복 확인 간격이지 게임 자원이 가득 차는 시간을 뜻하지 않습니다.
④ 첫 시험은 농장·목공소·광산만 선택합니다.
⑤ 아래 [일일 작업]도 확인해 사용하지 않을 항목은 해제합니다.
   길드를 사용할 때 레드루비를 쓰지 않으려면 [길드 레드루비 하루 한도]를 0으로 유지합니다.
⑥ [저장된 계정 선택 / 새 이름 입력]에서 실제 게임 계정에 맞는 구분을 선택하거나 입력합니다.
   예: 본계정 / 부계정 / 서버명_캐릭터명. 저장한 이름은 다음에 목록에서 다시 선택할 수 있습니다.
   빈 값은 기존 기본 기록을 사용합니다. 같은 계정에는 같은 구분을 유지하세요.
   이 목록은 기록 구분용입니다. 게임 로그인이나 계정을 자동으로 전환하지 않습니다.
   작업 선택·간격·기부 한도 설정은 뮤뮤별이며, 계정 이름을 바꿔도 별도 작업 설정을 불러오지 않습니다.
   실제 게임에서 직접 계정을 전환한 뒤, 이 목록도 맞춰 선택하고 저장하세요.
⑦ 반드시 [저장]을 누릅니다. 창만 닫으면 변경이 적용되지 않습니다.

여러 뮤뮤에 같은 설정을 쓰려면 [다른 뮤뮤에 적용]을 사용할 수 있습니다.
적용 대상과 복사되는 항목을 확인하고, 계정별 구분값과 실행 대상도 마지막에 점검하세요.

5. 작업별 의미와 재화 사용

[일반 작업]
- 농장 / 목공소 / 광산: 수령 가능한 식량·목재·광물을 확인합니다.
- 랭킹 수령: 받을 수 있는 랭킹 보상을 확인합니다.
- 월드보스 보상: 보상 표시가 있는 보스를 확인합니다. 현재 구현은 일반 모드 경로를 사용합니다.
- 유물 발굴: 유물 발굴 보상을 수령합니다.
- 수련: 보유한 수련 재료를 사용합니다. 단순 보상 수령이 아닙니다.
  수련을 새로 선택해 저장할 때 재료 사용 확인을 거칩니다. 동의하지 않으면 설정이 저장되지 않습니다.
  이전에 저장한 수련 선택은 그대로 유지됩니다. 원하지 않으면 수련을 해제하고 저장하세요.
- 가을맞이 수령: 해당 이벤트가 제공되고 화면을 인식할 수 있을 때 수령합니다.
  종료되었거나 화면이 바뀐 이벤트는 사용하지 않도록 해제하세요.

[일일 작업]
- 상점 무료 수령: 현재 무료로 받을 수 있는 항목을 확인합니다.
- 무료 소환: 화면에서 확인되는 남은 무료 횟수로 진행합니다.
- 패스 수령: 받을 수 있는 패스 보상을 확인합니다. 유료 패스 구매 화면은 제외합니다.
- 일일 던전: 남은 입장·소탕 횟수 및 무료 열쇠를 확인하며 진행합니다.
  입장권·소탕권 등 해당 게임 자원을 사용합니다.
- 길드: 출석·무료 기부 등 길드 작업을 진행합니다.
  [길드 레드루비 하루 한도]가 0이면 유료 기부를 하지 않습니다. 길드를 통째로 해제할 필요는 없습니다.
  새 설치와 기존 설정에 한도 값이 없는 경우 모두 기본값은 0입니다.
  유료 기부를 원할 때만 50 단위로 한도를 정하고 저장하세요. 최대값은 750입니다.
  설정한 한도는 뮤뮤·계정 구분별 한국시간 하루 기준으로 적용됩니다.
  결과가 미확인인 유료 기부도 사용량으로 예약해 남은 한도에서 차감합니다.
  미확인 결과를 성공으로 바꾸거나, 한도가 남았다는 이유로 같은 기부를 무조건 재시도하지 않습니다.
  과거 유료 기부 이력도 보존합니다. 기록이나 계정 이름을 바꿔 한도를 우회하지 마세요.

배포 비용이 무료라는 뜻을 모든 게임 작업의 재화 사용이 없다는 뜻으로 해석하지 마세요.
처음에는 필요한 항목만 선택하고 각 작업의 결과를 직접 확인하세요.

6. 한 번 실행과 자동 실행

[한 번 실행]
- 하단 [일반 작업]: 선택한 일반 작업을 한 차례 실행합니다.
- 하단 [일일 작업]: 선택한 일일 작업을 한 차례 실행합니다.
- 하단 [전체]: 선택한 일반 작업과 일일 작업을 한 차례 실행합니다.
- 범위를 고른 다음 [한 번 실행]을 누르세요.

[일반 자동 실행]
- 하단을 [일반 작업]으로 선택한 뒤 [일반 자동 실행]을 누릅니다.
- 선택한 일반 작업을 뮤뮤별 수령 간격에 맞춰 반복합니다.
- 일일 작업을 매일 자동 예약하는 버튼은 아닙니다.
- 일일 작업만 선택된 범위에서는 일반 자동 실행 대상이 없을 수 있습니다.

첫 사용은 [일반 작업] → [한 번 실행]으로 시험합니다.
정상적으로 수령하고 결과를 표시한 뒤 게임 내 절전 화면으로 돌아오는지 확인하세요.
이후 필요에 따라 작업을 추가하거나 일반 자동 실행을 켭니다.

게임 내 절전과 Windows PC 절전은 다릅니다.
게임 내 절전에서는 다음 작업을 위해 해제할 수 있지만, PC가 절전·종료되면 도우미가 동작하지 않습니다.

7. 중지·일시중지·자동 복구

- [일시중지]: 진행을 잠시 멈춥니다. 버튼이 [재시작]으로 바뀌면 눌러 이어갑니다.
- [중지] 또는 기본 단축키 F8: 현재 작업과 반복 대기를 중지합니다.
- 중지 키는 [작업 설정] → [키 변경]에서 바꿀 수 있습니다.
- [게임 자동 복구]: 선택한 뮤뮤의 게임 종료·인식 가능한 접속 오류를 감시하고 복구를 시도합니다.
- [게임 자동 복구]가 꺼져 있으면 작업과 별개로 감시하며 재접속하는 기능도 꺼집니다.
- [완전 중지]: 현재 작업·반복 대기를 중지하고 [게임 자동 복구]를 함께 끄며 이 설정을 저장합니다.
  이후 [게임 자동 복구]를 직접 다시 켜야 감시가 시작됩니다. 작업을 다시 시작하는 것만으로 켜지지 않습니다.
- 일반 [중지]와 F8은 작업 중지용입니다. 자동 복구까지 멈추려면 [완전 중지]를 사용하세요.
- 저장 오류가 표시되어도 현재 세션의 중지와 복구 끄기는 유지됩니다. 저장 오류를 해결한 뒤 상태를 확인하세요.
- 게임 로그인 인증, 서버 점검, 인식하지 못하는 새로운 팝업은 직접 확인이 필요할 수 있습니다.
- 도우미 창을 완전히 종료하면 감시와 반복 작업도 종료됩니다.

8. 여러 계정과 이전 기록

[오늘 작업]에서 선택한 계정들의 당일 진행 상태를 확인합니다.
[수령 기록]은 과거 수령 및 확인 기록이고, [실행 기록]은 동작 과정과 오류를 보는 곳입니다.
일일 기록은 한국시간 날짜와 뮤뮤·계정 구분을 기준으로 관리합니다.

새 실행 시 현재 무료 버튼과 남은 횟수를 확인해 일부 과거 미확인 기록을 재검토합니다.
그래도 결과가 불명확한 유료 기부 등을 성공으로 처리하거나 무조건 다시 누르지는 않습니다.

[미완료 이어하기]가 표시되면 남은 대상과 보류 이유를 읽고 실행하세요.
[보류 이유 보기] 또는 [수령 기록]에서 왜 멈췄는지 확인할 수 있습니다.
기록을 삭제하거나 계정 구분값을 바꿔 같은 유료 작업을 강제로 다시 실행하지 마세요.

9. 백그라운드 사용

도우미 실행 중 다른 PC 창을 사용하는 것은 가능합니다.
다만 뮤뮤 내부에서는 게임을 켜 두고, 같은 계정의 메뉴를 동시에 직접 조작하지 않는 것이 좋습니다.
게임 내 화면이 바뀌면 자동 작업이 대기하거나 중지할 수 있습니다.

뮤뮤를 최소화했을 때 화면 갱신이 멈추는 환경이라면 최소화를 풀고 다른 PC 창으로 가려 사용하세요.
게임을 켰는데 미리보기에는 뮤뮤 홈 화면이 나오는 경우, 뮤뮤의 앱 백그라운드 유지 관련 설정을 확인하고
해당 옵션을 끈 뒤 게임을 다시 열어 화면 확인을 해 보세요. 옵션 명칭은 버전마다 다릅니다.

PC·뮤뮤·도우미를 모두 실행 상태로 유지해야 합니다.
화면 밝기나 모니터만 꺼지는 것과 PC 자체가 절전 상태에 들어가는 것을 구분하세요.

10. 업데이트

상단 [업데이트]에서 방식과 새 버전 변경 내용을 확인합니다.
- [알림만 받기]가 기본값입니다. 새 설치뿐 아니라 업데이트 방식이 저장되지 않은 기존 설치도 적용됩니다.
- 알림 모드의 [새 버전 확인]은 확인만 합니다. 다운로드·설치·재시작을 시작하지 않습니다.
- 새 버전을 확인한 뒤 [업데이트 적용]을 누르면 직접 적용을 요청합니다.
- [자동으로 적용하기]를 선택하면 이후 새 버전을 확인했을 때 다운로드와 적용을 진행합니다.
- 적용 요청이 있더라도 작업 중이면 현재 작업을 마친 뒤 다시 시작합니다.
  일시중지된 작업은 중지 후 적용될 수 있습니다.
- 확인·다운로드·적용 대기 중에 [알림만 받기]로 바꾸면 자동 적용 요청을 취소합니다.
  이미 시작한 다운로드는 준비까지 끝날 수 있지만 자동 설치·재시작은 하지 않습니다.
  사용자가 [업데이트 적용]으로 직접 요청했거나 적용 도우미가 이미 실행된 경우는 취소 대상이 아닙니다.
- 방식 변경은 즉시 저장합니다. 저장에 실패하면 이전 방식으로 되돌리고 오류를 표시합니다.
설정과 수령 이력은 실행 파일과 별도 위치에 보관합니다.

다른 사람에게 처음 전달할 때는 이 무료배포 ZIP 또는 아래의 공식 EXE 주소를 전달하세요.
update.zip은 기존 설치의 업데이트용입니다. 첫 설치에는 무료배포 ZIP 또는 ChankiHelper.exe를 사용하세요.

11. 문제가 생겼을 때

뮤뮤가 목록에 안 나올 때
1) 뮤뮤와 게임이 실제로 실행 중인지 확인합니다.
2) 게임 메인 화면으로 돌아온 뒤 [뮤뮤 연결]을 다시 누릅니다.
3) 뮤뮤의 로컬 ADB 연결 허용 여부를 확인합니다.
4) [더보기] → [뮤뮤 연결 설정 · 진단]을 엽니다.
5) [자동 탐색]을 먼저 사용합니다. 경로와 주소를 비우면 자동으로 찾습니다.
6) 필요할 때만 [찾아보기]로 뮤뮤의 adb.exe 또는 adb_server.exe를 선택하고,
   실제 로컬 포트 또는 127.0.0.1:포트번호를 입력합니다. 7555는 예시일 뿐 모든 환경의 정답이 아닙니다.
7) [설정 저장] 또는 [저장 후 연결 진단]을 누릅니다.
   진단은 뮤뮤 탐색 → ADB·기기 연결 → 실행 중인 게임 → 화면 캡처·인식 결과를 표시합니다.
   진단은 기기 정보와 화면을 읽기만 하며 게임 터치나 앱 실행·복구를 수행하지 않습니다.
   작업·복구·업데이트가 진행 중이면 변경이 제한됩니다. [완전 중지] 후 종료될 때까지 기다리세요.
8) 계속 안 되면 실패 단계, 뮤뮤 버전과 진단 ZIP을 배포자에게 전달합니다.

화면은 나오는데 인식을 못 할 때
- 가로 16:9인지, 원하는 게임인지 확인합니다.
- 공지·구매·이벤트 팝업을 닫고 메인 화면에서 [화면 확인]을 누릅니다.
- [최근 화면]이 실제 게임 화면과 다른 경우 캡처 시각과 최소화 여부도 확인합니다.

시작해도 아무 작업이 없을 때
- [작업 설정]에서 실행 대상과 작업 체크 후 저장했는지 확인합니다.
- 하단의 [일반 작업 / 일일 작업 / 전체] 범위가 목적과 맞는지 확인합니다.
- 일일 작업은 [한 번 실행]을 사용하세요.

게임이 끊겼는데 복구하지 않을 때
- 도우미가 켜져 있는지, [게임 자동 복구]가 켜져 있는지 확인합니다.
- 해당 뮤뮤가 실행 대상에 포함되어 있는지 확인합니다.
- 일시중지 상태인지, PC가 절전 상태인지 확인합니다.
- 로그인 인증·점검 안내처럼 직접 조치가 필요한 화면인지 확인합니다.

완료 미확인·보류가 반복될 때
- [수령 기록]과 [보류 이유 보기]에서 해당 작업의 이유를 확인합니다.
- 현재 게임 화면과 시각을 함께 남겨 주세요.
- 과거 진단 화면만 보고 지금도 같은 오류라고 판단하지 않도록 최신 진단 ZIP을 저장합니다.

프로그램 실행이 차단될 때
- 임의의 재포장 파일 대신 공식 배포 주소의 파일인지 확인합니다.
- 보안 프로그램을 끄거나 예외를 무작정 추가하지 말고 경고 내용과 파일 출처를 확인하세요.

진단 ZIP 저장 방법
상단 [더보기] → [진단 파일 저장] → 저장 위치 선택.
배포자에게 프로그램 버전, 뮤뮤 버전, 문제 발생 시각, 진행 중이던 작업과 함께 전달하세요.
진단에는 게임 화면·계정 표시·실행 기록이 포함될 수 있으므로 공개 게시판에는 그대로 올리지 마세요.

12. 배포자가 전달할 파일

이 ZIP 전체를 그대로 전달하면 됩니다.
- ChankiHelper.exe: 실제 실행 파일
- 00_먼저읽기.txt: 빠른 시작
- 01_설치_세팅_사용법.txt: 이 설명서
- SHA256.txt: 실행 파일 확인용 해시

본인의 설정·수령 기록·진단 ZIP은 배포본에 넣지 마세요.
사용자 데이터는 Windows의 %LOCALAPPDATA%\MumuCollector 폴더에 별도로 저장됩니다.
이 배포 ZIP에는 해당 개인 데이터가 포함되어 있지 않습니다.

13. 개발자용 소스 실행

일반 EXE 배포본에는 Python 설치가 필요 없습니다. 아래 내용은 소스 코드를 직접 실행하는 경우에만 해당합니다.
Windows용 Python 3.12 64비트를 설치하고 소스 폴더 전체를 풉니다.
소스 폴더의 '창키 도우미.bat' 또는 START.bat를 실행하면 전용 .venv와 필요한 패키지를 준비합니다.
소스 실행에는 해당 폴더의 requirements.txt와 assets가 필요합니다. EXE 파일에 소스를 덮어쓰지 마세요.
개발자용 소스 ZIP이나 update.zip을 처음 설치할 사용자에게 무료배포 ZIP 대신 전달하지 마세요.

배포 확인
- SHA256.txt로 동봉한 ChankiHelper.exe의 해시를 확인할 수 있습니다.
- 테스트·Windows 실행·업데이트 검증의 최종 결과는 해당 버전 배포 기록을 확인하세요.
- 모든 사용자의 실제 뮤뮤 환경을 시험한 것은 아닙니다.
- 게임 업데이트로 화면이 달라지면 해당 기능의 추가 수정이 필요할 수 있습니다.
