창키 도우미 v0.7.7 검증

새 진단의 랭킹 수령 버튼 미인식 2건을 재현했습니다.
실제 오류 화면의 밝기, 색조, 채도, 대비, 해상도 변형 72건을 통과했습니다.
인식, 시설 수령, 월드보스, 확인창 관련 기존 검사 73개와 새 검사 6개를 통과했습니다.
새 검사는 기존 인식 실패 재현, 색감 변형, 비활성 버튼, 가림 화면, 독립 화면 확인, 모의 1회 수령을 검증합니다.

Windows EXE는 GitHub Actions에서 새로 빌드하며, UI, 트레이, 바로가기, 업데이트 적용 및 실패 복구 검사가 배포 전에 수행됩니다.
Windows 실행 검사 결과는 해당 릴리스의 exe-health.json, windows-validation.json과 Actions 기록을 기준으로 확인합니다.
실제 게임 조작은 캡처 및 모의 입력을 이용해 재현했으며 실제 사용자 PC를 원격 조작하지 않았습니다.
