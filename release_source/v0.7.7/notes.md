랭킹 수령 버튼을 인식하지 못해 대기하던 문제를 수정했습니다.

- 뮤뮤 ADB 캡처의 다른 글자 모양을 추가로 인식합니다.
- 같은 화면의 제목을 기준으로 밝기와 대비를 맞추며, 기존 비활성 버튼 구분 기준을 유지합니다.
- 월드보스 빨간 표시 수령과 준비중 제외 동작은 유지합니다.

기존 사용자는 프로그램의 **업데이트 → 새 버전 확인**으로 적용할 수 있습니다. 현재 수령 중이면 작업 완료 후 자동으로 설치하고 다시 시작합니다.

검증: 제공된 오류 화면의 색감 및 해상도 변형 72건, 관련 회귀 검사, Windows EXE 실행 및 업데이트 검증을 통과한 빌드만 배포됩니다. 실제 뮤뮤 게임 조작은 제공 캡처와 모의 입력으로 재현했습니다.
