창키 도우미 v0.7.20

- 패스 진입 위치를 상단 첫 번째 아이콘으로 수정
- 상단 순서: 패스 → 이벤트 → 월드보스 → 상점 → 가방 → 메시지 → 메뉴
- v0.7.18~0.7.19에서 패스 진입에 가방 위치를 사용한 오류 수정
- 테스트와 영상 프레임 재현 코드에도 들어 있던 잘못된 패스 위치 수정
- 패스 이외 6개 아이콘을 누르는 경우 완료로 기록되지 않는지 검증
- 월드보스는 확인된 세 번째 아이콘 위치 유지
- 이미 완료, 이미 수령, 입장 횟수 없음 표시 및 KST 자정 초기화 유지

검증 근거: 사용자가 직접 확인한 아이콘 순서와 전체 진단 화면. 이전 버전의 패스 위치 검증은 잘못된 가정을 공유했으므로 유효한 위치 검증이 아니었습니다.
수정한 위치를 기준으로 화면 전환 모의 테스트와 영상 추출 프레임 재현을 수행했습니다. 실제 사용자 MuMu에서의 실행은 아직 확인하지 않았습니다.
