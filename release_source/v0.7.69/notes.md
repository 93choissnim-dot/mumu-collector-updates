# 창키 도우미 v0.7.69

- 날짜별 실행 요약은 한국 날짜 기준으로 오늘을 포함한 최근 5일만 보관합니다. 오래된 요약은 다음 저장 때 정리되고 진단 ZIP에서 제외됩니다.
- 같은 계정과 작업에서 이후 수령 완료가 확인되고 미확인 입력이 없으면 관련 오류 자료를 기본 진단에서 제외합니다. 해결 확인 후 5일이 지난 자료는 자동 정리합니다. 계정 정보가 없는 구버전 자료는 임의로 해결 처리하지 않습니다.
- 진단 ZIP은 32MiB 이내로 제한하고 현재 기록과 최근 증거를 우선 포함합니다. 중복 또는 용량 때문에 제외한 자료는 목록과 사유를 남깁니다.
- 실패 사유가 결과보다 늦게 도착해도 실행 요약과 기록에 반영합니다. 오늘 작업 화면에서도 실패 사유를 볼 수 있습니다.
- 미확인 수령에는 요청 시각, 요청 버전, 작업명과 확인 방법을 표시합니다. 기록이 없는 시각은 추정하지 않습니다.
- 미확인 수령과 기부의 중복 입력 방지 기준을 유지합니다. 진단 자료 정리로 실행 기록을 지우거나 수령을 다시 시도하지 않습니다.

회귀 검사 및 실제 Windows 실행, 업데이트, 재시작과 복구 검증을 통과한 빌드만 배포합니다.
