화면 전환 오류와 결과 미확인 상태의 중복 실행을 줄였습니다.

- 공통 입력 단계에서 일시적 화면 미인식은 제한적으로 기다리고 연속 화면 재확인
- 다른 화면, 사라진 버튼, 바뀐 횟수는 클릭하지 않고 작업별 판단으로 복귀
- 시설, 랭킹, 월드보스, 발굴, 수련은 결과 미확인 상태에서 같은 수령 버튼 반복 입력 방지
- 시설 수령 완료는 연속 화면으로 확인하고 입력 기록은 재시작 후에도 유지
- 패스, 던전 입장과 소탕, 길드 던전 전투에 입력 전 영구 기록과 중복 실행 보류 추가
- 이미 완료 또는 횟수 소진을 확인하면 정상 완료 처리, 완료된 전투는 다음 횟수 진행
- 실행 중에도 오류 상세 열기 가능, 실행 중 재시도 차단을 Windows UI에서 검증
- 기록 창의 알 수 없는 작업과 삭제된 뮤뮤 처리, 일일 기록 읽기 오류 표시 개선

결과가 확인되지 않은 입력은 안전을 위해 보류될 수 있습니다. 실제 게임의 모든 화면 변경을 보장하지는 않습니다.
