창키 도우미 v0.7.65

- 길드 기부는 무료 기부 후 레드루비 50 기부를 이어서 실행하며, 게임의 일일 기부 완료 표시를 확인할 때까지 진행합니다.
- 매번 현재 비용 버튼을 새 화면에서 확인하고, 기부 요청을 먼저 기록한 뒤 입력합니다. 무료 기부부터 안정적인 기부 횟수 변화나 최종 완료 표시가 확인되어야 다음 기부를 진행합니다. 늦게 나타난 보상창만으로 성공 처리하지 않습니다.
- 결과가 불확실한 기부는 일시정지, 재접속, 재시작 후에도 자동으로 반복하지 않습니다.
- 이전 버전에서 유료 기부를 제외해 완료 처리한 기록은 미확인 입력이 없는 경우에만 다시 열어 남은 기부를 진행합니다. 다른 길드 완료 기록은 유지합니다.

재현 검사와 Windows 실행 및 업데이트 검증을 거쳐 배포합니다. 실제 사용자 MuMu 계정의 전체 루틴을 직접 실행한 검증은 아닙니다.
