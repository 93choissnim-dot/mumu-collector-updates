# 창키 도우미 v0.7.76

- 설정 저장에 실패하면 진행 중 작업과 자동 복구를 중단하고, 창 종료와 상태 갱신을 계속 처리합니다. 설정은 기존 파일을 보존하는 방식으로 저장합니다.
- 재접속 확인 과정이 오래 걸려도 이전 캡처를 새 화면으로 취급하지 않아 오래된 좌표의 터치를 차단합니다.
- 무료 소환·무료 상점에서 실제 입력 전에 차단된 신규 요청은 보류 기록을 정리합니다. 이미 보낸 입력이나 이전 실행의 미확인 기록은 유지합니다.
- 상점에서 목표 상품이나 큐브 미노출 표시를 확인하면 추가 스크롤을 즉시 멈춥니다.

Windows 회귀 검사, UI·실행파일 검사, 업데이트 재시작·복구 검사 및 배포 파일 무결성 검사를 통과한 빌드만 공개합니다.
