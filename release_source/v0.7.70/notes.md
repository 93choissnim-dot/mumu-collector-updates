# 창키 도우미 v0.7.70

- 월드보스 시즌 정산을 확인하면 랭킹·수령 입력을 멈추고 정산 대기로 표시합니다. 다음 예약에서 다시 확인하며, 과거 미확인 수령 기록은 보존합니다.
- 이전 버전의 무료 수령 미확인 기록은 현재 활성 버튼을 확인한 뒤 한 번 복구합니다. 과거 결과는 미확인 이력으로 보존하고 새 결과를 확인합니다. 새 버전에서 다시 미확인이 된 입력은 자동 반복하지 않습니다. 루비·던전 입장·수련에는 이 규칙을 적용하지 않습니다.
- 무료 수령과 보스별 보류 결과를 직접 확인해 반영할 수 있도록 기록 화면의 보류 해결을 확장했습니다.
- 진행 기록 저장에 고유 임시 파일·동기화·원자적 교체와 Windows 공유 충돌 재시도를 적용하고, 실패 시 구체적인 원인을 남깁니다.
- 입력 예약과 증거 저장 후 화면을 다시 확인합니다. 오래된 캡처가 새 화면으로 취급되지 않도록 시간을 계산합니다.
- 계정 프로필별 수령 이력·재시도·통계를 분리하고, 손상된 일일 기록을 안전하게 처리합니다. 자정을 넘긴 작업의 완료 날짜도 반영합니다.
- 진단 정리와 새 기록 저장의 충돌을 방지하고, 현재 미확인 입력과 최근 실패 자료를 먼저 내보냅니다. 진단 보관 5일과 ZIP 32 MiB 제한을 유지합니다.
- 소스판 실행 시 손상된 과거 업데이트 기록이 정상 복구를 막는 문제를 보완했습니다.

길드 기부는 레드루비를 포함한 가능한 횟수를 모두 사용하며, 길드 던전은 도전 횟수를 모두 사용한 뒤 전리품 횟수와 관계없이 수령하는 기존 설정을 유지합니다.
